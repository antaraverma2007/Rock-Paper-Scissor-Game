# 🎮 Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The player chooses Rock, Paper, or Scissors, and the computer randomly generates its choice. The score is updated after every round.

## ✨ Features

* 🪨 **Rock, Paper & Scissors Choices** — Select your move by clicking on the images.
* 🤖 **Computer Move** — Computer generates a random choice automatically.
* 🏆 **Score Tracking** — Keeps track of both user and computer scores.
* 🎯 **Game Result** — Displays whether you won, lost, or the game was a draw.
* 🎨 **Interactive UI** — Hover effects and dynamic message colors make the game engaging.

## 🎮 How to Play

1. Open the game in your browser.
2. Choose **Rock**, **Paper**, or **Scissors**.
3. The computer will randomly select its move.
4. The result of the round will be displayed.
5. The score will update automatically.
6. Continue playing to increase your score.

## 📌 Game Rules

| Your Choice | Computer Choice | Result   |
| ----------- | --------------- | -------- |
| Rock        | Scissors        | You Win  |
| Paper       | Rock            | You Win  |
| Scissors    | Paper           | You Win  |
| Same Choice | Same Choice     | Draw     |
| Rock        | Paper           | You Lose |
| Paper       | Scissors        | You Lose |
| Scissors    | Rock            | You Lose |
